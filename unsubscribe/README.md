# CAFU Unsubscribe

A simple page to handle unsubscribe requests for CAFU marketing emails. The page integrates with Google Sheets to track unsubscribe requests.

## Features

- Clean, responsive design
- Loading states and error handling
- Google Sheets integration for tracking
- Automatic email parameter handling

## Usage

Access the unsubscribe page at: https://cafu-faqs.github.io/unsubscribe/?email=example@email.com

The email parameter will be automatically processed and stored in the designated Google Sheet.
